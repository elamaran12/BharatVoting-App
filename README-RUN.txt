1. Download ZIP
2. Extract All
3. Open folder in VS Code
4. Double-click START-BHARAT-VOTING.bat
5. Browser opens at http://localhost:8000

Python 3.10+ required. No Maven, Node.js, MySQL or pip packages.

IMPORTANT: Aadhaar OTP and Voter ID verification are simulated demo functions. This app does not connect to UIDAI, Election Commission systems, real voter databases, or real phone numbers. Do not enter real Aadhaar information.
